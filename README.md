A one-line 1-star review from a houseplant about its human owner, written in sap.

> One star. She named me Fern, then planted a real fern next to me, and now guests compliment the fern while I do all the photosynthesizing.

`main.ts` writes the line to `/output/entry.txt` (138 characters, no trailing newline).
